# 分析资料与解释边界

## 情景模型
input_contract 区分 stochastic_joint 与 epistemic_bounds；joint_samples 是允许的联合随机输入观测，不能逐列打乱后声称仍来自同一人群。bounds_only 没有概率含义。app.domain.calculate 接收 option、输入和 shock_seed，相同种子重放相同内部冲击；方案比较可以保留共同随机数。
## 业务含义
敏感性对象包括预算额、超支风险和方案选择，定义可由实现者选择但需解释。全局贡献和局部导数不是同一问题。需要分离参数不确定性与内部模拟噪声，给出数值误差或收敛证据；对仅有范围的输入只能做相应范围/假设分析。补测价值应联系决策而非等同于方差贡献。
## 基准检查
analysis_cases 包括独立加性、强相关、纯交互、确定性模型和纯内部随机波动。加性独立例可用手算方差比例核对；完全相关变量的单独归因必须说明约定。模拟失败保留次数与原因，不能删掉失败后继续宣称原始风险分母。
