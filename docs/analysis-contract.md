# 分析资料与解释边界

## 情景模型
input_contract 区分 stochastic_joint 与 epistemic_bounds；joint_samples 是允许的联合随机输入观测，不能逐列打乱后声称仍来自同一人群。bounds_only 没有概率含义。app.domain.calculate 接收 option、输入和 shock_seed，相同种子重放相同内部冲击；方案比较可以保留共同随机数。

## 全局敏感性（app/sensitivity.py）
`POST /api/sensitivity` 以情景为锚，把联合观测按列乘以“情景值/样本均值”，再用交叉拟合多项式岭回归估计条件期望 E[T|X_S]，按 Shapley 效应把目标方差分摊到 participants、hours、hourly_cost。平移保持相关系数与变异系数，保留输入之间允许的联合关系；不对列独立打乱。平移后超出 capacity_limit 的行被剔除并报告，结论条件于可行设计。

目标包括各方案预算额、超支概率、期望超支额（超支按内部冲击的正态分布解析积分）、方案总成本差与决策后悔额。全部区间为联合样本行重抽样百分位区间，只覆盖抽样波动；每个目标另给样本外 R²、复合乘积驱动 R²、阶数稳健性与适用假设，便于回查贡献估计误差。

相关输入下单独份额会重复计算共享信息：响应同时给出单独可解释比例、排他份额、两两联合可解释比例与重叠扣减。Shapley 份额是分摊约定，不是唯一因果归属；当三个输入只经由乘积起作用时分不开，只能解释为联合贡献。

## 范围输入与内部噪声
overhead 只有 [1500, 3500]，没有概率分布：只报告端点与情景值的范围分析，不假设均匀或其他分布，也不进入 Shapley 分解。内部冲击与输入独立，超支概率与期望超支额不使用蒙特卡洛；同一参数换随机种子的重放只用于显示模拟噪声尺度，不计入参数重要性。目标方差中内部噪声占比单独列出。

## 补测价值
`information.sets` 给出每个单输入与组合的完美信息价值（按条件期望选择方案、相对当前固定方案的期望成本节省）、决策翻转概率及其自助区间。提供 measurement_costs 时按净价值排序并给出建议；未提供时只能按单输入完美信息价值排序，并明确这不是经费分配结论。所有价值都是完美信息上界，真实测量误差会使价值更低；它联系决策而非方差贡献。

## 基准检查
analysis_cases 包括独立加性、强相关、纯交互、确定性模型和纯内部随机波动。加性独立例可用手算方差比例核对；完全相关变量的单独归因必须说明约定。模拟失败保留次数与原因，不能删掉失败后继续宣称原始风险分母。app/sensitivity.py 的 `shapley_from_samples` 是独立入口，测试用已知答案的合成数据核对，不依赖业务数据的方向。
